# prnet_eval
Repository for the Evaluation of embedding-aware data partitioning as well as strategy for molecular representation on PRNet performance.

This project is an adaptation based on **PRnet: Predicting transcriptional responses to novel chemical perturbations using a deep generative model** ([GitHub Repository](https://github.com/Perturbation-Response-Prediction/PRnet)). Adaptations were made in the year 2026.
